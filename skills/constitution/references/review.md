# Independent review

Use a separate read-only subagent when the host and session permit delegation. Otherwise hand the packet to a different model in a separate read-only session. Include absolute artifact paths, the exact file hashes or Git revision under review, repository rules, source inputs, confirmed decisions, the focus below, and the check results. Ask for numbered findings citing a file and section or line, the consequence, and a suggested change. Keep edits and decisions in the calling session.

If neither review route is available, give the user the packet and mark independent review pending. If a report makes claims without showing which artifact it read, request a review with citations. Record the reviewer, revision, and findings or pending status. Recheck revised artifacts before reporting their status.

## Review focus

Review this project's constitution: specs/mission.md, specs/tech-stack.md, specs/roadmap.md. Also read README.md, AGENTS.md, GEMINI.md, and repository guidance if present, and the repo's build manifests and CI config. Review only these three files; ignore other working-tree changes. Look for: contradictions among the three files or with README.md; mission goals no roadmap phase serves, and phases that serve no goal or work against a non-goal; technologies a phase relies on that are missing from tech-stack.md; tech-stack claims (choices, versions, gate commands) that contradict the repo's actual manifests or CI; engineering standards too vague for an implementer to follow or a reviewer to check; roadmap phases that are too large (more than one capability, not shippable as one PR, horizontal layers instead of vertical slices, or a "Done when" that is missing, not binary, or depends on a later phase); phases out of dependency order or risky assumptions left needlessly late; a Phase 1 that isn't a walking skeleton; vague or unmeasurable goals; and gaps that would force a later feature spec to guess. For each finding, output a numbered item with the file, the issue, and the suggested change. Output findings only; do not rewrite the files.
