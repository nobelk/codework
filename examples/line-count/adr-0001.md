# ADR 1. Read the file with Python text iteration

The line-count command accepts one UTF-8 file path. FR1 requires consistent handling of empty files, blank lines, and an unterminated final line. NFR1 requires a standard-library implementation.

Use Python's text iterator to count lines incrementally. Reading the whole file and splitting it is also possible and would allocate memory for the entire fixture. The command must handle decode errors during iteration.

See [the design](design.md#2-system-architecture) and [requirements](prod_req.md#6-functional-requirements).
